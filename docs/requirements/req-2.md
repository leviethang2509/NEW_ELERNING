# Requirement 2

## Yêu cầu

Quét qua toàn bộ source code và tạo 1 trang document với đường dẫn /user-manual, hiển thị kiểu giống 1 trang document có sidebar menu bên trái và mỗi lần click vào menu item sẽ hiển thị tài liệu tương ứng.

Tài liệu sẽ bao gồm hướng dẫn sử dụng của toàn hệ thống, vai trò của tất cả các role.

Trang tài liệu này tạm thời sẽ là tài liệu nội bộ chỉ được xem bởi System Owner và Admin, và đây là static web, hãy tạo data bằng json và load trực tiếp lên web.

Tham khảo req-1 để nắm nghiệm vụ dự án.
